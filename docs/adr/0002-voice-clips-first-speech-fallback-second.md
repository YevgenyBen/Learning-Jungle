# Voice Clips first, Speech Fallback second

Everything spoken aloud comes from prepared Voice Clips shipped with the app; the device's own voice (Speech Fallback) is used only when a clip is missing. Browsers can't be relied on to have a Hebrew voice: the first prototype relied on one and stayed silent in Chrome on the developer's own machine. The clips are generated rather than recorded, from each item's voweled text so the pronunciation is unambiguous, with one female Azure neural Hebrew voice; Azure was picked because its free tier covers the whole collection, and running costs for this home-made app are meant to stay near zero. If their quality isn't good enough, the source will be reconsidered (an existing recording collection, for example) without changing how Games use them.
